ABSTRACT

Modern e-commerce logistics centers rely heavily on autonomous mobile robot (AMR) fleets. However, scaling fleet size introduces critical coordination bottlenecks: narrow-corridor deadlocks, inter-robot collisions, and resource contention. Traditional heuristic dispatchers fail under complex congestion dynamics.

This report presents the initiation, feasibility study, lifecycle methodology, and requirements specification for Project 25: Autonomous Warehouse Robot Fleet Coordination using Multi-Agent Reinforcement Learning (MARL). We formulate the coordination problem as a Decentralised Partially Observable Markov Decision Process (Dec-POMDP) and deploy QMIX (Centralised Training with Decentralised Execution - CTDE) benchmarked against Independent Q-Learning (IQL) and a Rule-Based Nearest-Task Dispatcher across fleet sizes N = 5, 10, and 20.

A dual-environment architecture is adopted: a canonical, high-throughput NumPy grid simulator drives all training and statistical evaluations, while PyBullet provides isolated 3D trajectory replay. Hard safety constraints are guaranteed via an action-masking safety layer that removes corridor-entering actions prior to policy decision-making. Evaluation integrity is strictly maintained through sealed SHA-256 hashed evaluation manifests committed prior to model training.

Chapter 1. Project Overview and Problem Scoping

1.1 Project Title

Autonomous Warehouse Robot Fleet Coordination Using Multi-Agent Reinforcement Learning

1.2 Background and Context

Modern e-commerce fulfillment centers require rapid, continuous transportation of goods from storage racks to packing stations. Automated warehouses deploy fleets of Autonomous Mobile Robots (AMRs) operating in structured grid layouts characterized by narrow bidirectional aisles, dense rack blocks, and designated transit corridors.

Standard logistics operations rely on centralized heuristic dispatchers (such as nearest-task allocation) and localized yielding rules. While effective for small fleets, these heuristics fail when robot density increases. Opposing robots in narrow aisles face deadlocks where neither can pass, and uncoordinated path choices generate severe localized bottlenecks that degrade throughput and waste energy.

1.3 Problem Statement

The central difficulty of coordinating an autonomous robot fleet is the multi-agent credit assignment problem under partial observability:

  1. Credit Assignment Dilemma: If robots receive individual rewards solely upon completing a personal delivery, an agent that yields at an intersection to relieve congestion receives zero short-term reward. Consequently, independent agents learn aggressive, selfish policies where yielding is unlearned, causing gridlock. Conversely, sharing global team rewards equally introduces high variance that obscures individual learning signals.
  2. Decentralised Execution Constraint: Due to communication latency and wireless packet loss in industrial warehouses, robots cannot rely on real-time inter-agent messaging during navigation. Each robot must execute movement decisions based purely on local sensor observations.
  3. Safety Corridor Invariants: Warehouses contain dedicated safety zones for human workers. Reinforcement learning policies optimizing purely for shortest paths will cut through human safety corridors unless constrained by deterministic safety guardrails.

1.4 Proposed AI/ML Solution

We deploy QMIX, a cooperative MARL algorithm operating under the Centralised Training with Decentralised Execution (CTDE) paradigm, benchmarked against Independent Q-Learning (IQL) and a Rule-Based Dispatcher:

  • Decentralised Agent Q-Networks: Each robot uses a recurrent neural network (incorporating a GRU) that maps local spatial observation histories (a 5x5 occupancy grid, target bearing vector, and load flag) to discrete movement utilities without reading global state.
  • Centralised Monotonic Mixer: During training, a mixing network combines individual agent utilities into a joint action-value Q_tot. Hypernetworks conditioned on global layout states dynamically generate the mixer weights, enforcing non-negativity via absolute value activations to satisfy the monotonicity condition (d Q_tot / d Q_a >= 0). This ensures decentralized greedy actions align with the joint optimum.
  • Dual-Environment Architecture (ADR-001): A fast, canonical NumPy grid simulator (WarehouseEnv) executes all training and evaluations at high frame rates, while PyBullet is isolated strictly for 3D trajectory demo replay (FR-7).
  • Hard Safety Action Masking (ADR-003): An action-masking safety layer sets the utilities of corridor-entering actions to -infinity before the argmax operation, guaranteeing zero human corridor violations.
